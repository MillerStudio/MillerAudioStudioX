Miller Audio Studio X
Versao: V6.6 Complete Routing Update
Data: 19/06/2026

ATUALIZACOES INCLUIDAS

V6.6.0 Routing Core
- Adicionada matriz A1-A5 por aplicativo.
- Cada app agora pode ter uma ou mais saidas ativas ao mesmo tempo.
- Estrutura interna de rota preparada para V6.7 Virtual Driver.
- Persistencia migrada para miller_mixer_persist_v660.
- Studio e Aplicativos usam a mesma rota global por app.

V6.6.1 Device Manager
- Tela de Dispositivos atualizada para trabalhar como base do Device Manager.
- Rotas A1-A5 continuam configuraveis na tela Rotas.
- Associacao de barramentos A1-A5 com dispositivos fisicos mantida por preset.

V6.6.2 Latency Monitor
- Latencia agora possui campos separados:
  - Input latency
  - Output latency
  - Round trip latency
- Dashboard, Studio e Configuracoes exibem status de latencia.
- Indicacao visual preparada:
  - OK ate 15 ms
  - Aviso ate 35 ms
  - Alto acima de 35 ms

V6.6.3 Routing Stability
- Polling e renderizacao mantidos leves.
- Rota por app persiste por 7 dias junto com volume, mute e solo.
- Log tecnico de roteamento criado no Rust: routing_core.log.
- Build frontend validado com sucesso.

IMPORTANTE
- Esta versao prepara o roteamento A1-A5 no Core e na interface.
- Roteamento fisico real independente para multiplas saidas ainda depende da V6.7 Virtual Driver.
- Sem driver virtual, o Windows/WASAPI ainda limita o roteamento fisico real por app.

COMO INICIAR O APP

1. Abrir Prompt na pasta do projeto:
cd C:\Programas\MillerAudioStudioX

2. Instalar dependencias:
npm install

3. Rodar em modo desenvolvimento:
npm run tauri dev

4. Gerar build:
npm run tauri build
