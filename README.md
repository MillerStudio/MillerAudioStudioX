# Miller Audio Studio X

Mixer de áudio profissional com IA integrada, roteamento por aplicativo e baixa latência.

## Versão atual

V6.6.5 Device Health & Channel View

## Como iniciar

```bash
npm install
npm run tauri dev
```

## Como gerar build

```bash
npm run tauri build
```
